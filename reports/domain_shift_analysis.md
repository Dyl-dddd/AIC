# 无标签 Train/Test 分布对照

统计来自本轮对全部 3200 张训练图和全部 788 张复赛 Test 图的实际解码，另从数字来源训练图中以固定随机种子抽取 300 张，生成每图一个 1387×1516 随机裁剪，用于和 Test 的 300 张同尺寸裁剪比较。裁剪只用于无标签分布审计，不用于拟合模型。

| 指标中位数 | 训练整图 3200 | Test 整图 488 | 训练模拟裁剪 300 | Test 裁剪 300 |
|---|---:|---:|---:|---:|
| 灰度均值 | 53.17 | 47.41 | 55.80 | 50.40 |
| 灰度标准差 | 23.46 | 21.66 | 13.12 | 9.29 |
| 局部对比度（512 像素预览的 32×32 块标准差中位数） | 2.99 | 2.63 | 3.87 | 3.34 |
| 拉普拉斯方差（预览） | 64.97 | 51.27 | 168.29 | 131.22 |
| 梯度均值（预览） | 10.39 | 9.31 | 16.73 | 15.10 |

尺寸构成存在明确差别：训练全部为 4096×3000，Test 是 488 张 4096×3000 与 300 张 1387×1516。Test 全部是数字前缀；训练包括数字与 `C` 两种文件名前缀。按匹配尺寸比较，Test 裁剪的灰度标准差中位数比训练模拟裁剪低 3.83，灰度均值低 5.41，局部对比低 0.53。探索性 KS 统计分别为 0.233、0.187、0.127；这些差异与训练裁剪位置、采集来源、真实测试缺陷构成均可能有关，不能推断原因或测试标签。

比较图：[整体直方图](train_test_histogram.png)、[六项特征](train_test_features.png)、[匹配尺寸裁剪](matched_crop_shift.png)。原始逐图数据见 [train_statistics.csv](train_statistics.csv)、[test_statistics.csv](test_statistics.csv)、[train_simulated_crop_statistics.csv](train_simulated_crop_statistics.csv)，统计汇总见 [matched_crop_shift.json](matched_crop_shift.json)。

训练决策：首先建立单模型整图基线并测量逐类、逐场景表现。若低对比子集确实掉分，再仅用训练图尝试温和对比/亮度增强；不得凭这张无标签分布表声称增强已提升分数。Test 仍只用于无标签统计和最终自动推理。
