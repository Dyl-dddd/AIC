# 截止日前缺陷攻坚实验计划

日期：2026-10-03 21:15（北京时间）。预测结果截止：2026-10-05 20:00。保护版本：V12 官方 67.92，R=0.9754、P=0.0053、AP50=0.4646、TP=872、FP=164549、FN=22。所有新方案未经平台验证均不得声称涨分或达到 72。

## 主张与反主张

| 主张 | 最低可信证据 | 相关实验 |
|---|---|---|
| C1：对齐真实提交协议的分层验证，比派生视图 Ultralytics mAP 更可靠地筛选候选 | 同一组原图、同一 JSON 导出阈值/类别/框映射，对照 V12 与新权重；全图/裁图和来源分层均报告 20P+60R+20AP50 参考分 | B0、B1 |
| C2：在一个检测器内训练经核验的困难背景与完整纵裂，比继续改现有 165421 个框的分数更有机会改善 AP | 高排名背景 FP 下降、纵裂 IoU0.5/0.75 提升，双视图 AP 和召回没有实质回退 | B2、B3 |

反主张：开发集小幅上涨不等于平台上涨；增加大量候选或无脑延长训练不算成功。V14、V31、V33 已在平台证伪了这种推断。

## 核心实验块

### B0：评分与类别核查（必须，先做）

- 核对官网九类输出要求与既有 V12 八类 JSON 的差异；不能假定气裂已被平台排除，也不能不经实验盲加气裂框。
- 在冻结 group split 上，按一次性固定列表建立约 62% 全图、38% 官方尺寸裁图的混合验证；源图及近重复必须同组。报告八类和九类两套参考 AP，并说明最终采用的官方解释仍未知。
- 用与最终 Test 完全相同的推理阈值、NMS、坐标映射、去重、类别过滤与唯一 JSON 格式重算 P/R/AP；另外分别报告数字来源全图、数字来源裁图、C 来源稀有类。
- 成功门槛：V12 的同协议开发结果可重现；图像 ID、尺寸、GT、预测条目与类别筛选均有可审计清单。失败则停止任何提交候选。
- 产物：`protocol_audit.json`、分层 PR/AP 表、九类/八类差异说明。预计 CPU 1–2 小时；复用既有候选缓存可减少 GPU。

### B1：V34 结果回传后的同协议重评（必须）

- 当前 V34 从强 Model A 权重继续 12 epoch，保留所有真实空图、有限正例切图与全高纵裂，`workers=0`；此阶段由用户云端运行。
- **不以 V34 脚本自动选择的九类派生视图 mAP 权重直接提交**。先对回传归档中的一个 V34 权重和 V12 用 B0 同一混合验证及分层协议比较；原 Model A 与其他 epoch 权重仍在云端，需要时才单独导出并比较，候选总数预先限制为最多 3 个，避免继续在 459 张 dev 上搜索几十个参数。
- 决策门槛：相对于 Model A 和 V12，主候选在数字全图与数字裁图的 AP50 均有明确正增益，混合参考分至少 +0.5，按钢卷/来源分组重采样后无明显负尾，且不能通过牺牲多个 TP 换表面 AP。若未通过，保留 V12，不进行 Test 推理。
- 失败解释：如果只在 V34 派生视图 mAP 上涨，则属于评测代理错位；若 V34 优于 Model A 却低于 V12，则仍不足以替换保护版本。
- 产物：`v34_protocol_comparison.json`，逐类 AP/TP/FP/FN 和 50 个最严重错误图清单。预计 1–2 GPU 小时。

### B2：困难背景短微调（条件启动；优先于再训练新架构）

- 仅在 B1 证明 V34 具有基础优势、而高排名背景 FP 仍为主瓶颈时启动。用已有模型在**训练集**挖各类高分 IoU<0.2 误报；人工只核验训练集的漏标、截断框与伪影类型，不接触 Test 真值/伪标签。按钢卷、相机和类别限额，配合原始正例与随机真空图防灾难性遗忘。
- 从最佳单权重低学习率继续 4–6 epoch，`workers=0`；每次只改变困难负例采样，保持输入尺寸、推理和导出一致。重点审查氧化铁皮、结疤、异物压入的高排名背景/跨类误报。
- 成功门槛：在同协议混合验证中，AP/参考分提高且召回损失被记录并符合净得分；按来源分层均不过度退化。失败即丢弃，不对 Test 做结果筛选。
- 产物：训练来源清单、核验记录、单权重 SHA256、分层比较。预计 2–4 GPU 小时 + 1 小时训练标注核验。

### B3：纵裂完整框消融（条件启动；与 B2 不叠加搜索）

- 只在 B1/B2 的错误审计确认纵裂仍是主要 AP 损失时，使用强权重做短周期全高条带微调；保留常规全图和负背景，限制纵裂重复比例，绝不回到 V26 从 COCO 重新训练或大规模过采样的方案。
- 报告同类 IoU0.5 与 IoU0.75、框高/宽比、完整端点覆盖和其他类别回退；不接受只放大框使开发集表面 TP 增加的方案，V31 平台已证伪全局几何修补。
- 成功门槛：两种尺寸视图均有定位收益，其他类总体 AP 不降；否则停止。预计 1–2 GPU 小时。

### B4：截止前交付（必须）

- 仅对通过 B1 或 B2/B3 的**单个**权重进行一次完整 Test 推理；核对 788 图像 ID、每框绝对坐标、合法类别、有限分数、唯一根 JSON、ZIP CRC 和权重 SHA256。Test 不用于训练或人工改答案。
- 预留至少 6 小时给完整推理、打包、平台算分延迟与回退；目标在 10 月 5 日中午前形成最后候选，不贴近 20:00 截止点。
- 平台分低于 67.92 则保留 V12；高于 67.92 才更新保护版本。最终代码/模型另按 10 月 7 日 23:59 要求提交。

## 运行顺序与预算

| 顺序 | 运行 | 启动条件 | 预计成本 | 停止条件 |
|---|---|---|---|---|
| M0 | B0 协议/类别审计 | 立即 | CPU 1–2 小时 | 无法复现 V12 或类定义不明时，先修协议 |
| M1 | 完成 V34、执行 B1 | V34 TAR 回传 | GPU 1–2 小时（重评） | 不优于 V12 或仅派生视图涨分 |
| M2 | B2 困难背景微调 | B1 有可信正增益 | GPU 2–4 小时 | 分层 AP/召回恶化 |
| M3 | B3 纵裂短微调 | B1 错误审计明确支持 | GPU 1–2 小时 | IoU/其他类不稳 |
| M4 | B4 Test 与提交 | 至少一个候选通过门槛 | 推理/打包/等待 ≥6 小时 | 无候选则保护 67.92 |

本计划不加入 LLM/VLM/扩散等无关模块，不启动多模型简单投票或加权平均。其关键风险是官方隐藏集与冻结 dev 的分布差异；门槛能减少弱候选，但不能保证 72 分。
