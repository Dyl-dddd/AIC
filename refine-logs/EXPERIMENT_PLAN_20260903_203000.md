# AIC 钢铁板材检测 V3 冲榜实验计划

**日期**：2026-09-03  
**当前开发集基线**：YOLO11s epoch 5，macro mAP50=0.20863，mAP50-95=0.11740，P=0.14908，R=0.39800，F2=0.25414，FP/图=5.113。  
**赛题边界**：最终线上方案为单模型；不调用商业闭源视觉 API；不人工修改测试结果；允许合规公开外部数据但必须披露来源；测试集不得回灌训练。

## 1. 目标与不可妥协的评价协议

目标不是“多训几轮”，而是在固定数据划分和固定原图评估器上得到可重复提升，并最终用官方排行榜验证。

| 阶段 | 放行目标 | 失败动作 |
|---|---|---|
| S0 免费优化 | mAP50 > 0.20863，或 F2 提升且 mAP50 不降超过0.003 | 回退参数，不重训 |
| S1 数据策略 | mAP50 >= 0.230；FP/图 <= 4.0；尾类召回不下降 | 保留基线，分析错误后换方向 |
| S2 结构/多尺度 | mAP50 >= 0.260；P >= 0.25；R >= 0.42 | 删除无收益复杂结构 |
| S3 冲榜候选 | 内部工程目标 mAP50 >= 0.30、P >= 0.30、R >= 0.45、FP/图 < 3 | 不包装成成功，继续误差驱动迭代 |

所有结果必须来自同一 `data/official_v2_20260831b/splits.json` 的459张完整原图 dev；`final` 在选模、阈值和后处理冻结前不得使用。先通过 P0 复现门禁，再进行算法归因；每项训练实验先用 seed 42，只有候选超过可复现基线至少0.01 mAP50才增加第二、第三个 seed。官方真实评分以榜单为准，本地 mAP 不是官方分数。

## 2. 已确认根因

1. **误检是第一瓶颈**：基线 P=0.149、FP/图=5.113；纵裂有825个预测但仅16个TP，伪影被大量识别成裂纹。
2. **尾类没有学稳**：气裂 dev 有10个GT但阈值0.05下0个TP；划伤23个GT仅5个TP。
3. **长训过拟合**：60轮长训最佳 mAP50=0.19749（epoch 35），低于5轮基线0.20863，之后继续下降。
4. **长尾采样未启用**：正式数据配置 `rare_repeat_cap=1.0`，等价于关闭重复采样。
5. **单一局部尺度受限**：当前主体为1024切片+1024全局缩放，小缺陷和贯穿长缺陷共享同一分辨率折中。
6. **当前并非完全从零训练**：`model=yolo11s.pt` 会直接加载 COCO 公开权重；`pretrained=none` 仅表示不再额外 load 第二套权重。后续报告不得误写为随机初始化。

## 3. 主张映射

| 主张 | 最低可信证据 | 实验块 |
|---|---|---|
| C1：难负样本与长尾重平衡能同时降低伪影误检并改善稀有类 | 同预算单因素对照；mAP、P/R、FP/图和每类TP/GT共同改善 | B1、B2 |
| C2：同一单模型的多尺度视图/P2可兼顾小缺陷和长条缺陷 | 按目标尺度和类别报告；增益不能只来自更多更新步数 | B3 |
| 反主张：收益只是更大模型、更多训练或挑最好seed | 等更新预算、相同预训练、相同split；删除无效复杂度 | 全部 |

## 4. 实验块

### P0：可复现性与评分协议（算法实验前必须通过）

- 完整复刻当前5轮基线两次：同一数据清单、划分、代码、预训练权重、batch、optimizer updates、seed和评估参数；保存代码/配置/数据/权重哈希。
- 当前两个同 recipe hash、同 seed=42 的独立第5轮结果分别为0.20863和0.15152，相差0.05711；日志还出现过CUBLAS确定性告警。告警只是待检假设，不能在复现实验前直接认定为原因。
- 启动前设置适配当前CUDA版本的 `CUBLAS_WORKSPACE_CONFIG`，同时固定Python/NumPy/PyTorch/Ultralytics随机源；记录worker数、AMP、CUDA/cuDNN版本和恢复训练状态。
- 对同一份候选缓存重复运行原图评价器，要求逐项指标一致，确认坐标回映射、IoU定义、空预测图和459张图覆盖不漂移。
- **通过门槛**：两次同seed基线mAP50差异不超过0.005；若未通过，其余实验只能作为smoke test，不得宣称算法提升。

### B0：提交与评估闭环（必须，先执行）

- 用当前最佳 epoch 5 权重在669张初赛测试图上生成 `submission.json`，ZIP根目录只放该JSON。
- 校验四个字段、九类拼写、绝对坐标、有限置信度、未知图名、空预测图和压缩包完整性。
- 利用现有 dev candidate cache，不重新跑网络，搜索 `merge={NMS,WBF}`、`iou={0.45,0.55,0.65}`、`local_iou={0.60,0.70,0.80}`、`edge_penalty={0.6,0.8,1.0}`。固定主指标为 mAP50，其次 mAP50-95和Recall；若平台最终采用单点P/R，再单独做类别阈值校准。
- **注意**：overlap、tile size、TTA、global pass 会改变网络候选，不能伪装成“缓存免费搜索”。
- 预估：0.5–1 GPU小时（主要是必要的候选重算）；缓存重放只需CPU分钟级。

### B1：Hard Negative Mining（最高优先级训练实验）

- 用冻结基线扫描训练原图，只从已知空XML图或与GT IoU<0.1的高置信预测中采集难负区域；禁止人工修改测试集。
- 首轮候选阈值0.15；每类/每原图设上限，去重并保留来源清单，避免某一种水渍纹理淹没训练分布。
- 与原训练集混入比例从10%开始，只改变难负样本，不同时改采样、结构或增强。
- **测试问题**：当前5.113 FP/图是否主要由可重复背景伪影导致。
- **成功门槛**：mAP50至少+0.01，Precision至少+0.05，FP/图至少下降20%，Recall下降不超过0.02。
- **失败解释**：若P升而AP/R显著降，难负比例过高或含漏标；若无变化，误检主要来自分类/尺度而非背景覆盖。

### B2：长尾重平衡（最高优先级训练实验）

- 单因素测试 `rare_repeat_cap=3.0`；记录重复后每类曝光量和实际optimizer.step，使总更新预算与基线可比较。
- 若简单重复有效，再测试稀有类 copy-paste；只从训练集实例提取，带边缘融合与尺度约束，不贴到明显不合理背景。
- 当前Focal会改变YOLO质量软标签的最优点，不能与重复采样同时首次启用；先保持BCE。BCE+repeat有效后再测试Varifocal/QFL或经单元测试的soft-target-safe focal。
- **成功门槛**：总体mAP50至少+0.01；气裂/划伤/夹杂平均AP或召回至少+0.05；FP/图增加不超过15%。
- **失败解释**：尾类升、头类大跌说明重采样过强；所有类无变化说明有效正样本/标签质量而非曝光次数是瓶颈。

### B3：多尺度与P2（第二阶段）

- 先做同一stock YOLO11s的多视图训练：768局部切片上采样到1024、原1024切片、1280或1536大视图/全局视图；每个原图与每类限制采样数量，按优化器更新而不是图片数对齐预算。
- 随后单独跑YOLO11s-P2。P2必须使用经过审计的COCO层迁移，并先通过小样本学习门槛；此前P2诊断86.21%低于stock 92.63%，不能预设P2一定获胜。
- 只有stock多尺度和P2至少一个分别有效，才运行“P2+多尺度”交互项。
- **成功门槛**：mAP50至少+0.015；小框/气裂/夹杂召回提升，同时纵裂/划伤不下降超过0.02。
- **失败解释**：小框升而长框降时调整视图采样比；P2无增益则保留更简单stock模型。

### B4：工业域增强与外部预训练（第三阶段）

- 增强只模拟灰度产线变化：亮度/对比度、gamma、轻微高斯噪声、运动/高斯模糊、轻微scale/translate；Mosaic从0.3起，MixUp不超过0.05，最后10轮关闭Mosaic。每组先做A/B，不全开。
- 去模糊与CLAHE保持实验候选，不默认对全部图像启用；水渍和纹理可能被锐化成假缺陷。
- GC10/NEU只用于公开来源的工业纹理预训练，再在官方9类上微调；不强行把不同标签体系映射成官方类别。报告来源、许可、规模和处理方式。
- 只有上述数据/训练改进已超过基线，才试YOLO11m或更大输入；更大模型不是第一优先级。
- **成功门槛**：mAP50再提升至少0.01，并在留域/亮度扰动诊断上不退化。

### B5：最终单模型冻结与打榜

- 选择一个checkpoint；允许同一个模型的滑窗、多尺度输入与tile内融合，但不进行多结构/多阶段模型投票或权重平均。
- 在dev上冻结NMS、类别阈值和推理参数；随后只评估一次final holdout。
- 使用冻结配置生成669图提交，保存代码/权重/数据清单/参数/哈希。每天最多5次提交；先提交最可信候选，不把5次全部用于无假设试错。
- 官方初赛榜单反馈只用于选择下一次合规实验方向，不对测试图人工标注、不制作伪标签。

| 顺序 | Run ID | 唯一主要改动 | 轮数 | 4090预估 | Go/Stop |
|---|---|---|---:|---:|---|
| 1 | V3-P000 | 同seed复刻5轮基线×2 | 2×5 | 1–2h | 差异<=0.005才允许算法归因 |

时间是4090上的保守估计，第一轮实测后修正。不得一次性启动全部矩阵；每个闸门失败就停止对应分支。完整核心路线预计20–40 GPU小时，而不是无上限搜索。

## 6. 明确不做

- 不继续把当前60轮模型训练到100/150轮；它已经过拟合。
- 不同时开启P2、Focal、repeat、CLAHE、去模糊和Mosaic后把总提升归因给某一模块。
- 不使用YOLO11s+YOLO11m+DETR投票/WBF等多模型集成。
- 不以降低阈值制造“高召回”并宣称mAP提高。
- 不把测试集重复图、人工观察或伪标签回灌训练。
