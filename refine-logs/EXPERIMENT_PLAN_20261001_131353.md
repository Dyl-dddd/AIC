# V13 高分辨率互补专家实验计划

版本：20261001_131353

## 目标与现状

官方保护结果为 67.92（recall 0.9754、precision 0.0053、mAP50 0.4646）。短期瓶颈不是召回率本身，而是剩余漏检、框定位质量以及海量低置信候选的排序。V13 不覆盖 V12 排序器，而是提供新的高分辨率证据源。

官方分数：`20 * precision + 60 * recall + 20 * mAP50`。

## 可证伪主张

1. 主张：从已验证 YOLO11m 独立微调的 1536 召回专家和定位专家，至少一个能在冻结双视图中产生稳定的独有真阳性或更高 IoU 匹配。
2. 辅助主张：在不降低召回超过 0.002 的前提下，V12 的逐类排序器能够吸收该互补证据并使双视图加权代理分数提高至少 0.20。

反解释：收益可能只是导出更多候选造成的开发集偶然增益。必须同时报告 TP、FP、mAP50、双视图一致性和按官方组隔离的 OOF 结果，不能只比较候选数量。

## 固定控制

- 固定 `official_v2_20260831b/splits.json` 和 balanced-v3 数据配方。
- 两个分支都从 SHA-256 为 `02f1f09b80addd462e8781d08c27b744b0175b4ab04dcc2df5191892c3a23090` 的 Model B 独立初始化。
- 单卡 RTX 4090、AMP、确定性训练、workers=0；Ultralytics 固定 8.3.169。
- 训练阶段不访问 Test；冻结选择阈值固定为 0.0001，不做阈值扫描。
- 67.92 是保护回退，不因开发代理提升而自动替换。

## 实验块

1. 预检 GPU、版本、数据、split 与旧权重哈希，并执行 CUDA 前后向见证。
2. 训练 `v13_hires_recall_bce`：1536、12 epochs、受限空间增强，偏向覆盖漏检。
3. 独立训练 `v13_hires_localize_vfl`：1536、12 epochs、Varifocal 与更高 box/DFL 权重，偏向定位及质量排序。
4. 仅对两个预注册 `last.pt` 和旧 Model B 做完整 original/grid-crops 冻结验证；归档逐图预测与审计证据。
5. 返回本地后，按官方组做 V12+专家的 OOF 覆盖审计、逐类融合与稳定性检验。
6. 只有双视图门槛通过后才生成 Test 候选；官方 67.92 继续保留。

## 放行与停止门槛

- 训练完整性：权重初始化张量与参数元素 100% 匹配，optimizer step 和 batch health 审计完整，无非有限 loss。
- 专家互补性：至少一个专家在每个视图新增不少于 3 个独有 TP，或 mAP50 相对旧 Model B 提高至少 0.005。
- 融合放行：original 与 grid-crops 的 OOF 加权代理分均改善，综合增益至少 0.20，任一视图 recall 下降不得超过 0.002。
- 若仅候选数/FP 上升而 TP、mAP50 和融合代理分均无稳定改善，则停止该路线。
- 不用训练切片 val、单视图偶然峰值或官方 Test 反复试探选超参数。

## 算力预算

- 两个 1536 分支顺序训练约 8–11 GPU 小时。
- 三个 checkpoint 的双视图冻结验证约 2–5 GPU 小时。
- 总预算约 10–16 GPU 小时；不引入额外 GPU 框架，不重装现有 CUDA PyTorch。
