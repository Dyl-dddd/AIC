# 复赛实验计划

**问题**：复赛测试集由 4096×3000 整图和 1387×1516 的 2×3 裁块混合组成，初赛模型存在输入形态与亮度域偏移。
**方法主张**：用精确复刻的裁块视图对初赛最强权重做低学习率微调，可提升复赛裁块召回，同时保留整图能力。
**日期**：2026-09-21

## Claim Map

| Claim | Why It Matters | Minimum Convincing Evidence | Linked Blocks |
|---|---|---|---|
| C1 裁块匹配微调提升召回 | 300/788 张为新裁块形态 | 冻结 dev 裁块召回提升，原图 dev 不明显下降 | B1, B2, B3 |
| C2 收益不是单纯多训几轮 | 避免把 epoch 数误当方法收益 | 同一初始权重、同一训练预算下比较旧视图与复赛网格视图 | B2, B4 |

反主张：收益只来自更多训练、测试泄漏或更高内存配置。所有比较固定初始权重、split、epoch、batch 和选择规则；复赛测试不生成伪标签。

## Experiment Blocks

### B1 数据与构造审计
- 数据：3200 张有标注训练图、669 张初赛测试图、788 张复赛测试图。
- 指标：尺寸分布、灰度均值/对比度/清晰度、直方图 JS 散度、ZIP 完整性。
- 成功标准：确认复赛裁块几何并生成无损、无路径冲突的派生测试目录。
- 优先级：MUST-RUN。

### B2 epoch25 零微调基线
- 系统：`best_score_proxy_epoch25.pt`。
- 验证：冻结原图 dev + 复赛 2×3 裁块式 dev。
- 指标：召回优先，mAP50 次之，分类别召回用于定位尾类退化。
- 成功标准：得到可复现的零微调基线；不把训练集裁块当泛化证据。
- 优先级：MUST-RUN。

### B3 复赛网格微调
- 数据：冻结 train/dev，2×3 网格裁块 + 1024 全局视图，repeat cap=3。
- 初始权重：epoch25；30 epoch；AdamW；lr0=1e-4；batch=2；每 5 epoch 保存。
- 成功标准：裁块 dev 召回相对 B2 上升，原图 dev 召回下降不超过 0.5 个百分点。
- 失败解释：若裁块上升但整图明显下降，说明遗忘；需混入旧 1024 滑窗视图或缩短微调。
- 优先级：MUST-RUN。

### B4 视图消融
- 对比：旧 1024 滑窗微调 vs 复赛 2×3 网格微调；其余设置完全相同。
- 成功标准：网格版本在裁块 dev 上更高且原图不劣。
- 优先级：仅在 B3 未过门槛时运行。

### B5 最终推理
- 对 4096×3000 使用 1024 overlap=0.25 滑窗 + 全局视图。
- 对 1387×1516 同时保留滑窗与全局视图，低阈值优先召回。
- 输出先做格式、数量、边界和图像 ID 完整性检查，再提交。
- 优先级：MUST-RUN。

## Run Order and Milestones

| Milestone | Goal | Runs | Decision Gate | Cost | Risk |
|---|---|---|---|---|---|
| M0 | 数据安全与域偏移审计 | ZIP 审计、300 张/域像素样本 | 788 张均可读且几何确认 | 已完成 | 低 |
| M1 | 生成复赛匹配训练数据 | grid2x3 + global | split 无泄漏、标签合法 | 约 20–60 分钟 CPU | 中 |
| M2 | 微调 | 30 epoch 单次 | loss 有限、无 OOM | 先跑 5 epoch 外推，预计 8–18 GPUh | 中 |
| M3 | 选 checkpoint | epoch 5/10/15/20/25/30 | 裁块召回提升且原图不退化 | 约 1–3 GPUh | 中 |
| M4 | 推理与提交 | 最佳 checkpoint | 788 个 image_id 覆盖完整 | 约 1–3 GPUh | 低 |

## 风险与缓解

- 无复赛真值：只给预测区间，不宣称本地实测分数。
- 过拟合裁块：保留独立原图 dev 双门槛；必要时回退旧权重。
- 内存：batch=2、workers=0、cache=false、训练期不验证。
- 伪标签合规风险：默认禁用；仅在赛规明确允许后单独评估。
